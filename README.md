# proyecto_III_trading
Instructions for running the code.

1.- Download all the files  
2.- Create a virtual environment (.venv)   
3.- Install the packages needed utilizing the file "requirements.txt"  
4.- Start an mlflow instance "using mlflow ui --backend-store-uri sqlite:///mlflow.db"  
5.- Run "main.py" to create models and they will be uploaded to mlflow ui  
6.- Analyze models in the interface by typing "mlflow ui" in terminal  
7.- Run the desired models in complement.py modifying the route in which the given model is located
